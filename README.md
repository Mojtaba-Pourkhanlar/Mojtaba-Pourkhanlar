## 👨‍💻 About Me

I'm a **Frontend Developer** focused on building scalable, maintainable, and high-performance web applications with **React.js**, **Next.js**, and **TypeScript**.

A significant part of my work is centered around **Web GIS and interactive geospatial applications**, where frontend engineering meets maps, spatial data, and complex user interfaces.

I care about writing software that is not only functional, but also easy to maintain, fast to use, and pleasant to interact with.

* ⚛️ Building modern applications with React.js & Next.js
* 🗺️ Developing interactive Web GIS and map-based interfaces
* ⚡ Focused on frontend performance and scalable architecture
* 🧩 Creating reusable and maintainable UI systems
* 🌍 Open to remote opportunities and challenging projects
